CSS

O CSS é o acronimo de folha de estilo em cascata, ele é usado para estilizar documentos html. Ele deve ser aplicado as tags HTML, usado para formatações diversas do documento, tais como: mudança de cores, fontes e posicionamentos dos elementos HTML.

Tipos de seletores: seletor de tipo

Os seletores de tipo são aqueles que representam tags HTML, eles sao utilizados para aplicar as regras CSS. Neste exemplo estamos usando seletores de tipo. Analise a página
