Exemplo 25 HTML CSS - vinculaçao de arquivos css

vinculação de arquivos css

A vinculação de arquivos css é o processo de conectar uma folha de estilo a uma página html para que os elementos visuais da página recebam formatação.

Existem basicamente duas formas de vinculação de arquivos css em documentos html: a vinculação externa e a vinculação interna. Sendo que a forma mais reomendada é a externa, pois facilita a manutenção e o reuso das regras css.

Vinculação externa

A vinculação externa como dito anteriormente é a mais recomendada em projetos reais. Nesse tipo de vinculação, o css fica em um arquivo separado e o html faz a ligação entre a tag por meio da tag link. Neste documento estamos usando a vinculação externa.

Caracteristicas da vinculação externa

  • Separa a estrutura html e a apresentação(regras css)
  • Facilita a manutenção
  • Permite reutilizar o mesmo css em varias páginas
  • deixa o projeto muito mais organizado

Vinculação interna

A vinculação interna de arquivos css em documentos html se da de suas formas (incorporada e inline), essa vinculação ocorre diretamente no documento html por meio do atributo style. Ela deve ser utilizada com cuidado, pois dificulta a manutenção e polui o html, uma vez que mistura o conteudo com a apresentação.
