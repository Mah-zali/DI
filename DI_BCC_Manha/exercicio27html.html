Exemplo 27 html css - vinculação interna (inline)

A vinculação internqa CSS é um metodo para aplicar estilos a um documento html, inserindo o codigo css diretamente na página(incorporado) ou como componente html(inline).

Esse estilo de vinculação não é muito recomendado, pois dificulta a manutenção da página, uma vez que se tivermos varios componentes e varias páginas deveremos mudar entrar cada uma das páginas para fazer as alterações.

Vinculação inline

A vinculação inline é a forma de aplicar estilos diretamente a um elemento html, usando o atributo style na tag de abertura. Essa abordagem vincula o estilo exclusivamente ao elemento que estiver sendo criado. É importante dizer que essa abordagem nao deve ser usada de forma comum, pois dificulta a manutenção da pagina.
