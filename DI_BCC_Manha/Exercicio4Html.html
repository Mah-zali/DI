Exemplo 4 HTML - Estrutura Geral

Este exemplo mostra a estrutura mínima de um documento HTML. A seguir são descritas as principais tags utilizadas nessa estrutura geral.

  • <DOCTYPE html>:É uma instrução html, essa tag define o tipo do documento html.
  • <html>: é o elemento central do documento, é o container do documento html, ele engloba toda a página.
  • <head>: Essa tag contém os metadados que serão interpretados pelo navegador, tais como títulos e metatags de codificação.
  • <body>: Esse bloco é responsável por deixar visível o conteúdo destinado aos usuários. Ou seja, todo o conteúdo do documeno html.
